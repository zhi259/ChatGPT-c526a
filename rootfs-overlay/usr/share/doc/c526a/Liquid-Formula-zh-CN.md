# Liquid Formula 简体中文快速使用说明（HiWiFi C526A）

本说明对应固件内的 Liquid Formula 1.x 页面。菜单入口通常为 **服务 → Liquid Formula**；具体子页面名称可能因上游版本略有变化。

## 1. 先理解它的用途

Liquid Formula 包含订阅转换、JSON 模板管理、FakeHTTP、FakeSIP、Logo/Favicon 和可选内核网络调优。它**不包含、也不直接运行 sing-box 代理核心**；生成的 JSON 需要由 OpenWrt-momo 或其他兼容 sing-box 的运行时读取。

FakeHTTP / FakeSIP 属于数据包混淆辅助程序，不是 VPN，也不是加密层。两项服务默认关闭，建议先保持关闭，了解接口、NFQUEUE 和 mark/mask 的用途后再单独测试。

## 2. 订阅转换基本步骤

1. 进入 **服务 → Liquid Formula → Singbox Formula（订阅转换）**。
2. 填入服务商提供的订阅地址，并选择服务商支持的 User-Agent；不确定时先使用页面预设。
3. 将默认访问密码 `890716` 改为自己的密码。转换器可能监听路由器的多个接口，不要把它直接暴露到公网。
4. 选择需要使用的 JSON 模板。若使用 OpenWrt-momo，可从 Momo 模板开始；若使用其他运行时，应确认模板的输出格式与运行时兼容。
5. 启用转换服务并点击 **保存并应用**，等待状态变为 **运行中且已就绪**。如果显示“运行中（尚未就绪）”，请查看页面日志和订阅地址/User-Agent。
6. 使用 **刷新订阅** 拉取最新订阅，使用 **检查生成的配置** 验证转换结果。
7. 确认输出路径正确后，点击 **更新输出文件**。默认输出路径可能是 `/etc/momo/profiles/config.json`；更新文件本身不会自动重启 sing-box/momo，必要时需在实际运行时重新加载配置。

## 3. FakeHTTP / FakeSIP

- **FakeHTTP**：面向 TCP 流量的混淆辅助功能，可管理载荷内容，并配置接口、出站/入站方向、IPv4/IPv6、TTL、NFQUEUE 和 mark/mask。
- **FakeSIP**：面向 UDP 流量的 SIP 相关混淆辅助功能，可配置端口过滤和 SIP 标识。
- 两项服务默认关闭。错误的接口、流量方向、队列号或 mark/mask 会影响流量处理，可能与策略路由、VPN、QoS 冲突。请一次只启用一项，在确认规则和回退方式后再测试。

## 4. Tuning Utility（调优工具）

此页提供 Logo/Favicon、内核参数查看和可选网络调优。内核调优默认关闭；除非了解拥塞控制、队列调度、SYN backlog 及 irqbalance 的影响，否则先不要启用。更改前建议备份设置。

## 5. 温度显示和路由器地址

C526A 的顶部温度栏通过 `/sbin/tempinfo` 读取系统已暴露的 `hwmon` 温度传感器，可显示 MT7615E 2.4 GHz 模块及两颗 QCA4019 5 GHz 模块温度；v11 不再额外显示重复的独立无线温度概况板块。IPQ4019 CPU/SoC 温度仅在内核有对应可读传感器时显示；当前设备树和系统未暴露该接口，因此不会显示伪造的 CPU 温度。

全新默认配置的 LAN 管理地址为 **http://192.168.5.1/**，网段为 `192.168.5.0/24`。DHCP 继续使用默认地址池。若升级时保留了自定义配置，已有的自定义 LAN 地址会保留；如要验证默认网络，请先备份并在刷机时不保留旧配置。

## 6. 网络不通时的检查

1. LAN 侧应看到 `lan2`、`lan3`、`lan4`，WAN 侧接口名为 `wan`；具体物理网口对应关系请逐个插拔网线确认。
2. 在路由器 SSH 中检查 `ip link show`、`ip route`、`ubus call network.interface.wan status`。
3. 路由器本机能访问公网但 LAN 客户端不能访问时，检查 LAN 客户端是否获得 `192.168.5.x` 地址、默认网关是否为 `192.168.5.1`，以及防火墙的 LAN→WAN 转发和 WAN masquerading。
4. 避免把 WAN 上游网段也设成 `192.168.5.0/24`；LAN 与 WAN 使用不同网段。

## 7. 备份与安全

- 刷固件前备份配置、校准数据和原厂分区信息。
- 不要将 `factory.ubi` 和 `sysupgrade.bin` 混用；首次安装和系统内升级所用的镜像不同，请按构建说明选择。
- 订阅地址、访问密码与生成的配置都可能包含敏感信息，避免将日志、订阅链接或配置文件公开分享。
